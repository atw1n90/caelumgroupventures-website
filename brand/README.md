# Caelum Group Ventures — Brand Assets

The mark: five stars of the constellation Caelum (the chisel) joined into a "C".
The open star at the tail is the unfinished edge — work still being carved.

## Files
- svg/mark-gold-on-dark.svg — primary mark on #07090F (also the favicon)
- svg/mark-gold-transparent.svg — primary mark, transparent background
- svg/mark-ink-on-light.svg — ink variant for light backgrounds
- svg/mark-gold-dark-on-light.svg — gold variant for light backgrounds (#B07C20 for contrast)
- svg/mark-tiny-no-lines.svg — simplified for very small sizes (<20px)
- svg/favicon.svg — browser tab icon
- png/ — raster renders (512/192/64/32)

## Palette
- #07090F Deep Space (background)
- #0B0E17 Panel
- #D9A94E Brass Gold (accent; use #B07C20 on light backgrounds)
- #EDF0F7 Starlight (text)
- #8B93A7 Nebula Gray (secondary text)

## Type
- Instrument Serif (italic) — display & wordmark
- Instrument Sans — body
- Space Mono — labels & system text

## Rules
- Clear space: one star diameter around the mark
- Minimum size: 20px (below that use mark-tiny-no-lines.svg)
- Don't recolor, rotate, add glow/gradients, or place on busy imagery
